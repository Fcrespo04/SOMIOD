2. Diferenciar o Formato (JSON para HTTP, XML para MQTT)
Pergunta: "Atualmente o sistema envia XML para todos. Altere o controlador para que, se o endpoint for HTTP, seja enviado um JSON {'msg': 'novo registo'}, mantendo o XML apenas para o MQTT."

Onde mexer: MiddleWare/Controllers/ContainerController.cs

Local: Dentro do método CreateChild, no ciclo foreach dos endpoints.

Código a alterar (ContainerController.cs):

C#

// ... dentro do foreach (var ep in endpoints) ...

string endpointLower = ep.ToLower().Trim();

// Envio MQTT (Mantém-se XML)
if (endpointLower.StartsWith("mqtt://"))
{
    MqttHelper.PublishToBroker(ep, topico, xmlMessage);
}
// Envio HTTP (Muda para JSON)
else if (endpointLower.StartsWith("http://") || endpointLower.StartsWith("https://"))
{
    // --- ALTERAÇÃO AQUI ---
    string jsonMessage = "{ \"msg\": \"novo registo\" }";
    _ = HttpHelper.SendPostRequest(ep, jsonMessage); // Envia o JSON em vez do xmlMessage
}

Pergunta: "O envio de notificações HTTP é instável. Altere o código para que, caso o envio HTTP falhe (excepção), seja gravada uma linha na consola de Debug com a mensagem 'FALHA NO ENVIO PARA: [url]'."

Onde mexer: MiddleWare/Controllers/ContainerController.cs (se quiseres tratar o erro no fluxo) OU HttpHelper.cs (se quiseres tratar dentro do método). A forma mais segura para o exame é no Controller, pois o método do Helper pode não ter try/catch exposto.

Código a alterar (ContainerController.cs):

C#

// ... no bloco else if (http) ...
else if (endpointLower.StartsWith("http://"))
{
    try 
    {
        // Tenta enviar
        HttpHelper.SendPostRequest(ep, xmlMessage); 
    }
    catch 
    {
        // Se der erro, faz o log pedido
        System.Diagnostics.Debug.WriteLine($"FALHA NO ENVIO PARA: {ep}");
    }
